ROLE & IMPACT

각 기술은
서로 다른 문제를 해결

AI Agent Orchestration

  • 목적: 복합 생활 업무 자동 처리
  • 통신: HTTP 요청 + SSE 응답
  • 효과: 전문 처리, 맥락 유지, 업무 API 연결

Kafka Notification

  • 목적: 업무 이벤트를 알림 서비스에 전달
  • 통신: Kafka 메시지 + Web Push 또는 SSE
  • 효과: 책임 분리, 확장성, 중복 방지

STOMP/WebSocket Chat

  • 목적: 입주민과 관리자의 즉시 상담
  • 통신: WebSocket 양방향 연결
  • 효과: 실시간 메시지, 방 단위 전달, JWT 통제

AI가 반복 업무를 처리하고, Kafka가 중요한 변화를 전달하며,
WebSocket이 사람의 즉각적인 소통을 완성합니다.

ALPHATRAGEN 13
세 기술은 목적이 다릅니다. AI는 반복 업무 자동 처리, Kafka는 중요한 변화의 안정적 전달, WebSocket은 사람과 사람의 즉각적인 소통을 담당합니다.
